# Rasaprakāśasudhākara

### YRps, Adhyāya 1

śaśikalākalitaṃ hi śubhānanaṃ śivanidhānamatho ṛṣipūjitam  
jananapālanasaṃharaṇātmakaṃ hariharaṃ prathamaṃ praṇamāmyaham //

kumudakundasitāmbaradhāriṇīṃ vimalamauktikahārasuśobhitām  
sakalasiddhagaṇair api sevitām aharahaḥ praṇamāmi ca śāradām //

vadanakuṃjaram abhradaladyutiṃ trinayanaṃ ca caturbhujavāmanam  
kanakaratnasuśobhitaśekharaṃ gaṇapatiṃ prathamaṃ praṇamāmyaham //

giriśadhāma sadā mahadadbhutaṃ sakalarogavighātakaraṃ param  
sakalasiddhisamūhaviśāradaṃ praṇatapāpaharaṃ bhavapāradam //

 *(Inhaltsverzeichnis)* 
prathamaṃ pāradotpattiṃ kathayāmi yathātatham  
tataḥ śodhanakaṃ tasya tathāṣṭādaśa karma ca //

caturdhā baṃdhavijñānaṃ bhasmatvaṃ sūtakasya ca  
dhātūnāṃ śodhanaṃ caiva māraṇaṃ guṇavarṇanam //

aṣṭau mahārasāḥ samyak procyante 'tra mayā khalu  
tathā coparasānāṃ hi guṇāḥ śodhanamāraṇam //

drutipātaṃ ca sarveṣāṃ kathayāmi savistaram  
ratnānāṃ guṇadoṣaśca tathā śodhanamāraṇam //

krāmaṇaṃ raṃjanaṃ caiva drutimelānakaṃ rase  
rasāṃśca śatasaṃkhyākān kathayāmi savistarāt //

auṣadhīnāṃ samākhyātā bhedāścatvāra eva ca  
divyauṣadhyo rasauṣadhyaḥ siddhauṣadhyastathā parāḥ //

mahauṣadhya iti proktā yaṃtrāṇyatha puṭāni ca  
mūṣāścaiva hi dhātūnāṃ kautukāni samāsataḥ //

vājīkaraṇayogāśca śukrarataṃbhakarāsta  
nātisaṃkṣepavistārāt graṃthe 'smin parikalpitāḥ //

 *(sūtotpatti (mithilfe einer schṆnen Frau))* 
himālayātpaścimadigvibhāge girīndranāmā ruciro 'sti bhūdharaḥ  
tatsannidhāne 'tisuvṛttakūpe sākṣādraseṃdro nivasatyayaṃ hi //

kumārikārūpaguṇena yuktā svalaṃkṛtā vāhavare 'dhirūḍhā  
tatrāgatā kūpamavekṣamāṇā nivartitā sā mahatā javena //

pradhāvitaḥ sūtavaraścaturṣu kakupsu bhūmau patito hi nūnam //

paritaḥ parvatātsamyak kṣetraṃ dvādaśayojanam  
vistīrṇaṃ ca suvṛttaṃ hi sūtakasya samīritam //

tanmṛdaḥ pātane yaṃtre pātitaḥ khalu rogahā  
jāyate ruciraḥ sākṣād ucyate pāradaḥ svayam //

 *(mercury:: subtypes:: caste (after emanation from the well))* 
kūpādviniḥsṛtaḥ sūtaś caturdikṣu gato dvijaḥ  
kṣatriyo vaiśyaśūdrau ca caturṇāṃ jāyate khalu //

 *(mercury:: subtypes:: colour)* 
śvetā kṛṣṇā tathā pītā raktā vai jāyate chaviḥ  
prācyāṃ yāmyāṃ pratīcyāṃ ca kauberyāṃ ca diśi kramāt //

 *(mercury:: subtypes:: colour:: use)* 
śvetaḥ śvetavidhāne syāt kṛṣṇo dehakarastathā  
pītavarṇaḥ svarṇakartā rakto rogavināśakṛt //

sarva ekīkṛtā eva sarvakāryakarāḥ sadā  
sevitāḥ sarvarogaghnāḥ sarvasiddhividhāyakāḥ //

itthaṃ sūtodbhavaṃ jñātvā na rogaivārdhyate khalu  
śodhito māritaścaiva krāmitaḥ sāritaḥ śubhaḥ //

 *(pāradnā āṭh saṃskār athavā karm)* 
svedanaṃ mardanaṃ caiva mūrcchanaṃ syāttadutthitam  
pātanaṃ rodhanaṃ samyak niyāmanasudīpane //

tathābhrakagrāsamānacāraṇaṃ ca krameṇa hi  
garbhadrutirbāhyadrutiḥ proktaṃ jāraṇakaṃ tathā //

sāraṇaṃ krāmaṇaṃ proktaṃ vedhakarma ca raṃjanam  
sevanaṃ pāradasyātha karmāṇyaṣṭādaśaiva hi  
uddeśato mayātraiva nāmāni kathitāni vai //

 *(pāradadoṣāḥ)* 
doṣāḥ pañca samuddiṣṭāḥ pāradānāṃ bhiṣagvaraiḥ  
malo viṣaṃ tathā vahnir mado darpaśca vai kramāt  
mūrcchāṃ mṛtyuṃ madaṃ caiva sphoṭaṃ kuryuḥ śirobhramam //

 *(pāradakañcukāḥ)* 
kañcukāḥ sapta sūtasya kathayāmi yathārthataḥ  
nāmāni kathayāmyeṣāṃ devīśāstrānusārataḥ //

mṛcchailajalaśulbāyonāgavaṃgasamudbhavāḥ  
sūtake kaṃcukāḥ sapta tataścaiva viṣopamāḥ //

 *(mercury:: use of śodhana)* 
dvādaśaiva hi doṣāḥ syur yaiśca niṣkāsitā dvijaiḥ  
teṣāṃ hi rasasiddhiḥ syād apare yamasannibhāḥ  
tasmāddoṣāpaharaṇaṃ kartavyaṃ bhiṣaguttamaiḥ //

 *(svedana)* 
tatra svedanakaṃ kuryād yathāvacca śubhe dine  
sūtasya svedanaṃ kāryaṃ dolāyaṃtreṇa vārtikaiḥ //

kṣārau cāmlena sahitau tathā ca paṭupaṃcakam  
trikaṭu triphalā caiva citrakeṇa samanvitā //

puṣpakāsīsasaurāṣṭryau sarvāṇyeva tu mardayet  
oṣadhāni samāṃśāni rasād aṣṭamabhāgataḥ //

kṛtvāndhamūṣāṃ teṣāṃ tu tanmadhye pāradaṃ kṣipet  
triguṇena suvastreṇa bhūrjapatreṇa veṣṭayet //

guṇena kāṣṭhakhaṇḍe vai baddhāṃ tu rasapoṭalīm  
lambāyamānāṃ bhāṇḍe tu tuṣavāriprapūrite //

tridinaṃ svedayetsamyak svedanaṃ tadudīritam //

 *(2. mardana)* 
atha mardanakaṃ karma yena śuddhatamo rasaḥ  
prajāyate vistareṇa kathayāmi yathātatham //

khalve vimardayetsūtaṃ dināni trīṇi caiva hi *(khalva:: dimensions)*  
atha khalvapramāṇaṃ hi vakṣye tatra mayādhunā //

kalāṃgulas tadāyāmaś cotsedho 'pi navāṃgulaḥ  
vistareṇa tathā kuryān nimnatvena ṣaḍaṅgulam //

dvyaṃgulaḥ pṛṣṭhavistāro madhye 'timasṛṇīkṛtaḥ *(pestle:: size)*  
ardhacandrākṛtiścāpi mardako 'tra daśāṃgulaḥ //

 *(mardana (cont.))* 
sūtaḥ pañcapalastasmin mardayet kāñjikaistryaham  
bahirmalavināśāya rasarājaṃ tu niścitam //

uṣṇakāṃjikatoyena kṣālayet tadanantaram //

 *(3. mūrchana)* 
ataḥparaṃ pravakṣyāmi pāradasya tu mūrcchanam  
mūrcchanaṃ doṣarahitaṃ saptakañcukanāśanam //

svarjikā yāvaśūkaśca tathā ca paṭupaṃcakam  
amlauṣadhāni sarvāṇi sūtena saha mardayet //

khalve dinatrayaṃ tāvad yāvannaṣṭatvam āpnuyāt  
svarūpasya vināśena mūrcchanaṃ tadihocyate  
nirmalatvam avāpnoti granthibhedaśca jāyate //

 *(4. utthāpana)* 
athotthāpanakaṃ karma pāradasya bhiṣagvaraiḥ  
karaṇīyaṃ prayatnena rasaśāstrasya vartmanā //

dolāyaṃtre tataḥ svedyaḥ pūrvavaddivasatrayam  
sūryātape mardito 'sau dinamekaṃ śilātale  
utthāpanaṃ bhavetsamyak mūrchādoṣavināśanam //

 *(5. pātana)* 
pātanaṃ hi mahatkarma kathayāmi suvistaram  
tridhā pātanamityuktaṃ rasadoṣavināśanam //

ūrdhvapātastvadhaḥpātas tiryakpātaḥ krameṇa hi *(ūrdhvapātanayantra)*  
ūrdhvapātanayaṃtrasya lakṣaṇaṃ tadihocyate  
mṛṇmayī sthālikā kāryā cocchritā tu ṣaḍaṃgulā //

mukhe saptāṅgulāyāmā paritastridaśāṃgulā  
iyanmānā dvitīyā ca kartavyā sthālikā śubhā //

kṣāradvayaṃ rāmaṭhaṃ ca tathā hi paṭupañcakam  
amlavargeṇa saṃyuktaṃ sūtakaṃ taistu mardayet //

lepayettena kalkena adhaḥsthāṃ sthālikāṃ śubhām  
uparisthām adhovaktrāṃ dattvā saṃpuṭamācaret //

sabhasmalavaṇenaiva mudrāṃ tatra prakārayet  
culyāṃ sthālīṃ niveśyātha dhānyāgniṃ tatra kārayet //

tasyopari jalādhānaṃ kāryaṃ yāmacatuṣṭayam  
svāṅgaśītalatāṃ jñātvā ūrdhvaṃgaṃ grāhayedrasam //

ūrdhvapātanayaṃtraṃ hi tadevaṃ parikīrtitam *(5.2. adhaḥpātana)*  
pūrvoktāṃ sthālikāṃ samyak viparītāṃ tu paṃkile  
garte tu sthāpitāṃ bhūmau jvālayenmūrdhni pāvakam //

yāmatritayaparyaṃtaṃ adhaḥ patati pāradaḥ  
adhaḥpātanayaṃtraṃ hi kīrtitaṃ rasavedibhiḥ //

 *(5.3. tiryakpātana)* 
pūrvoktairauṣadhaiḥ sārdhaṃ rasarājaṃ vimardayet  
tiryagghaṭe rasaṃ kṣiptvā tanmukhe hyaparo ghaṭaḥ //

kanīyānudare chidraṃ chidre cāyasanālikām  
nālikāṃ jalapātrasthāṃ kārayecca bhiṣagvaraiḥ //

adhastādrasayaṃtrasya tīvrāgniṃ jvālayedbudhaḥ  
yāmatritayaparyaṃtaṃ tiryakpāto bhavedrasaḥ //

yaṃtrāṇāṃ pātanānāṃ ca tritayaṃ sukaraṃ khalu //

kathitaṃ hi mayā samyak rasāgamanidarśanāt //

 *(6. rodhana)* 
adhunā kathayiṣyāmi rasarodhanakarma ca  
yatkṛte ca palatvaṃ hi rasarājasya śāmyati //

sindhūdbhavaṃ daśapalaṃ jalaprasthatrayaṃ tathā  
dhārayedghaṭamadhye ca sūtakaṃ doṣavarjitam //

pidhānena yathā samyak mudritaṃ mṛtsnayā khalu  
nirvāte nirjane deśe dhārayed divasatrayam //

anenaiva prakāreṇa rodhanaṃ kuru vaidyarāṭ //

 *(7. niyāmana)* 
ataḥparaṃ pravakṣyāmi pāradasya niyāmanam  
jalasaiṃdhavasaṃyukto ghaṭastho hi rasottamaḥ  
dinatrayaṃ sveditaśca vīryavānapi jāyate //

 *(8. dīpana)* 
athedānīṃ pravakṣyāmi rasarājasya dīpanam  
bubhukṣā vyāpakatvaṃ ca yena kṛtvā prajāyate //

rājikā lavaṇopetā maricaṃ śigruṭaṃkaṇe  
kāsīsasaṃyutā kāṃkṣī kāṃjikena samanvitaiḥ //

dināni trīṇi saṃsvedya paścāt kṣāreṇa mardayet  
anenaiva prakāreṇa dīpanaṃ jāyate dhruvam //

tīvratvaṃ vegakāritvaṃ vyāpakatvaṃ bubhukṣutā  
balavattvaṃ viśeṣeṇa kṛte samyak prajāyate //

 *(8.1. dīpana: mukhotpādana)* 
mukhotpādanakaṃ karma prakāro dīpanasya hi  
kathayāmi samāsena yathāvadrasaśodhanam //

aṣṭādaśāṃśabhāgena kanakena ca sūtakaḥ  
nimbūrasena saṃmardyo vāsaraikamataḥparam //

kṣāraiśca lavaṇai ramyaiḥ sveditaḥ kāṃjikena hi  
kṣālite kāṃjikenaiva vaktraṃ bhoktuṃ prajāyate //

 *(8.2. dīpana: mukhotpādana (2))* 
tāpyasatvaṃ kalāṃśena hemnā tad dviguṇena ca  
taptam āyasakhalvena taptenātha pramardayet //

vyaktaṃ hi rasacukreṇa kṣāreṇa caṇakasya hi  
jaṃbīrapūrakajalair mardayedekaviṃśatim //

vāsare yāmamekaṃ tu pratyekaṃ hi vimardayet  
yātudhānamukhaṃ samyak yātyeva hi na saṃśayaḥ //

dvitīyo dīpanasyaivaṃ prakāraḥ kathito mayā  
sūtasyāṣṭau ca saṃskārāḥ kathitā dehakarmaṇi //

tathā ca daśa karmāṇi dehalohakarāṇi hi //

 *(9. grāsamāna)* 
athedānīṃ pravakṣyāmi bhakṣaṇaṃ cābhrakasya hi  
karoṭividhinā samyak kartavyaṃ lohasaṃpuṭam //

jalayaṃtrasya yogena viḍena sahito rasaḥ  
bhakṣayatyeva cābhrasya kavalāni na saṃśayaḥ //

 *(jalayantra)* 
ato hi jalayaṃtrasya lakṣaṇaṃ kathyate mayā  
suvṛttaṃ lohapātraṃ ca jalaṃ tatrāḍhakatrayam //

tanmadhye sudṛḍhaṃ samyak kartavyaṃ lohasaṃpuṭam  
lohasaṃpuṭamadhye tu nikṣiptaṃ śuddhapāradam //

biḍena sahitaṃ caiva ṣoḍaśāṃśena yatnataḥ  
catuḥṣaṣṭyaṃśakaṃ cābhrasattvaṃ saṃpuṭake tathā //

saṃpuṭaṃ mudrayetpaścāt dṛḍhayā toyamṛtsnayā  
vahnimṛttikayā vāpi saṃdhirodhaṃ tu kārayet //

culyāṃ niveśya taṃ yaṃtraṃ jalenoṣṇena pūritam  
kramādagniḥ prakartavyo divasārdhakameva hi //

evaṃ kṛte grāsamānaṃ bhakṣayennātra saṃśayaḥ  
anenaiva prakāreṇa ṣaḍgrāsaṃ bhakṣayed dhruvam //

bhakṣite cābhrasattve tu sarvakāryeṣu siddhidaḥ *(viḍamāna)*  
mānaṃ mānavihīnena kartuṃ kena na śakyate //

tasmānmayā mānakarma kathitavyaṃ yathoditam  
catuḥṣaṣṭyaṃśato bījaṃ pāradānmukhakārakam //

paścād dvātriṃśabhāgena dātavyaṃ bījamuttamam  
tataḥṣoḍaśabhāgena bījasya kavalaṃ nyaset //

rasādaṣṭamabhāgena dātavyaṃ bhiṣaguttamaiḥ  
caturthenātha bhāgena grāsa evaṃ pradīyate //

tathā ca samabhāgena grāsenaiva ca sādhayet  
biḍena ṣoḍaśāṃśena kṣudhito jāyate rasaḥ //

yadā jīrṇo bhaved grāsaḥ pātitaśca viḍena hi //

 *(biḍa)* 
kāsīsasindhulavaṇasauvarcalasurāṣṭrikāḥ  
gaṃdhakena samaṃ kṛtvā viḍo 'yaṃ vahnikṛd bhavet //

 *(10. cāraṇa)* 
atha garbhadruteḥ karma cāraṇaṃ guṇavardhanam  
kathayāmi yathātathyaṃ rasarājasya siddhidam //

tāpyasatvābhrasattvaṃ ca ghoṣākṛṣṭaṃ ca tāmrakam  
samabhāgāni sarvāṇi dhmāpayetkhadirāgninā //

bhastrikādvitayenaiva yāvadabhrakaśeṣakam  
tadabhrasatvaṃ sūtasya cārayetsamabhāgikam //

 *(11. garbhadruti)* 
anenaiva prakāreṇa triguṇaṃ jāraṇaṃ rase  
garbhadruterjāraṇaṃ hi kathitaṃ bhiṣaguttamaiḥ //

 *(12. bāhyadruti)* 
bāhyadrutividhānaṃ hi kathyate gurumārgataḥ  
abhrasatvaṃ hi mūṣāyāṃ vajravallīrasena hi //

sauvarcalena saṃdhmātaṃ rasarūpaṃ prajāyate  
abhradruteśca sūtasya samāṃśairmelanaṃ kṛtam //

tena bandhatvamāyāti bāhyā sā kathyate drutiḥ  
bāhyadrutikriyākarma śivabhaktyā hi sidhyati //

guroḥ prasādātsatataṃ mahābhairavapūjanāt  
śivayorarcanādeva bāhyagā sidhyati drutiḥ //

 *(13. jāraṇa)* 
atha jāraṇakaṃ karma kathayāmi suvistaram  
abhrakaṃ tāpyasatvaṃ ca samaṃ kṛtvā tu saṃdhamet //

abhraśeṣaṃ kṛtaṃ yacca tatsatvaṃ jārayedrase  
evaṃ pūtidvayenaiva ghanasatvaṃ hi sādhayet //

dhātuvādavidhānena lohakṛt dehakṛnna hi  
gajavaṃgau mahāghorāv asevyau hi nirantaram //

sādhitaṃ ghanasatvaṃ tad retitaṃ rajaḥsannibham  
bubhukṣitarasasyāsye nikṣiptaṃ vallamātrakam //

raso gadyāṇakasyāpi turyabhāgaḥ prakīrtitaḥ  
tāmrapātrasthamamlaṃ vai saiṃdhavena samanvitam //

kṣīreṇa sahitaṃ vāpi prahitaṃ dvidināvadhi  
jātaṃ tutthasamaṃ nīlaṃ kalkaṃ tatprocyate budhaiḥ //

kalkenānena sahitaṃ sūtakaṃ ca vimardayet  
dinatrayaṃ taptakhalve dhautaḥ paścācca kāṃjikaiḥ //

sthāpayetkāṃsyapātre tu tadūrdhvādho viḍaṃ nyaset  
rasasyāṣṭamabhāgena saṃpuṭaṃ kārayettataḥ //

bhūrjapatrairmukhaṃ ruddhvā sūtreṇaiva tu veṣṭayet  
saṃpuṭaṃ vāsasāveṣṭya dolāyāṃ svedayettataḥ //

gomūtreṇāmlavargeṇa kāṃjikena dinaṃ dinam  
aśmapātre'tha lohasya pātre kācamaye 'thavā //

uṣṇakāṃjikatoyena kṣālayitvā rasaṃ tataḥ  
dṛḍhe caturguṇe vastre kṣiptvādhaḥ pīḍanādrasaḥ //

nipatatyanyapātre tu sarvo 'pi yadi pāradaḥ  
tadābhraṃ jāritaṃ samyak daṇḍadhārī bhavedrasaḥ //

grāsamāne punardeyaṃ abhrabījamanuttamam  
aṣṭagrāsena sarvaṃ hi jārayed gurumārgataḥ //

evaṃ kṛte samaṃ cābhraṃ sūtake jīryati dhruvam  
svahastena kṛtaṃ samyak jāraṇaṃ na śrutaṃ mayā //

 *(mercury:: "age" according to jāraṇa)* 
samābhre jārite samyak daṇḍadhārī bhavedrasaḥ  
bālaśca kathyate so'pi kiṃcitkāryakaro bhavet //

dviguṇe triguṇe caiva kathyate 'tra mayā khalu  
caturguṇe 'bhrake jīrṇe kiśoraḥ kathyate mayā //

jīrṇe pañcaguṇe cābhre yuvā caiva rasottamaḥ  
ṣaḍguṇe jārite tvabhre vṛddhaścaiva rasottamaḥ //

saptāṣṭaguṇite cābhrasatve jīrṇe 'tivṛddhakaḥ  
sarvasiddhikaraḥ so 'yaṃ pāradaḥ pāradaḥ svayam //

anenaiva prakāreṇa sarvalohāni jārayet //

 *(14. sāraṇa)* 
athedānīṃ pravakṣyāmi vedhavṛddheśca kāraṇam  
mahāsiddhikaraṃ yatsyāt sāraṇaṃ sarvakarmaṇām //

dhūrtapuṣpasamākārā mūṣāṣṭāṅguladīrghikā  
mukhe suvistṛtā kāryā caturaṃgulasaṃmitā //

mṛṇmayā sāpi śuṣkā ca madhye 'timasṛṇīkṛtā  
anyā pidhānikā mūṣā sunimnā chidrasaṃyutā //

śuddhaṃ sujāritaṃ sūtaṃ mūṣāmadhye nidhāpayet *(sāraṇātaila)*  
matsyakacchapamaṇḍūkajalaukāmeṣasūkarāḥ //

ekīkṛtya vasāmeṣām evaṃ tailaṃ tu sāraṇam  
bhūnāgaviṭ tathā kṣaudraṃ vāyasānāṃ purīṣakam //

tathaiva śalabhādīnāṃ mahiṣīkarṇayormalam  
rasasya ṣoḍaśāṃśena caiteṣāṃ kalkamādiśet //

paṭena gālitaṃ kṛtvā tailamadhye niyojayet *(sāraṇā (cont.))*  
sāraṇārthe kṛtaṃ tailaṃ tasmin taile supācayet //

bījaṃ ca kalkamiśraṃ hi kṛtvā mūṣopari nyaset  
pidhānena dvitīyena mūṣāvaktraṃ nirundhayet //

bhasmanā lavaṇenaiva mūṣāyugmaṃ tu mudrayet  
mūṣikāyāstribhāgaṃ hi khanitvā vasudhāṃ kṣipet //

tadūrdhvaṃ dhmāpayetsamyak dṛḍhāṃgāraiḥ kharāgninā  
evaṃ saṃjāritaṃ bījaṃ rasamadhye patatyalam //

bandhamāyāti sūtendraḥ sārito guṇavān bhavet  
prathamaṃ jāritaścaiva sāritaḥ sarvasiddhidaḥ //

no jāritaḥ sāritaśca kathaṃ bandhakaro bhavet  
gurūpadeśato dṛṣṭaṃ sāraṇaṃ karma cottamam //

hastānubhavayogena kṛtaṃ samyak śrutaṃ nahi //

 *(15. krāmaṇa)* 
atha krāmaṇakaṃ karma pāradasya nigadyate  
śāstrātkṛtaṃ na dṛṣṭaṃ hi yathāvat krāmayedrasam //

karṇamalaṃ mahiṣīṇāṃ strīdugdhaṃ ṭaṃkaṇena sammiśram /  
etānyeva samāni ca kṛtvā dravyāṇi mardayecca dinam //

viṣaṃ ca daradaścaiva rasako raktakāntakau  
indragopaśca tuvarī mākṣikaṃ kākaviṭ tathā //

kalkametad adhordhvaṃ hi madhye sūtaṃ nidhāpayet  
kācacūrṇaṃ tato dattvā cāndhamūṣāgataṃ dhamet //

anena krāmaṇenaiva pāradaḥ kramate kṣaṇāt  
idaṃ krāmaṇakaṃ śreṣṭhaṃ nandirājena bhāṣitam //

tāpyasattvaṃ tathā nāgaṃ śuddhaṃ krāmaṇakaṃ tathā  
bījāni pāradasyāpi kramate ca na saṃśayaḥ //

 *(16. vedhana)* 
atha vedhavidhānaṃ hi kathayāmi suvistaram  
yena vijñātamātreṇa vedhajño jāyate naraḥ //

dhūrtatailamaheḥphenaṃ kaṃguṇītailameva ca  
bhṛṅgītailaṃ viṣaṃ caiva tailaṃ jātīphalodbhavam //

hayamāraśiphātailam abdheḥśoṣakatailakam  
etānyanyāni tailāni viddhi vedhakarāṇi ca //

siddhasūtena ca samaṃ marditaṃ vedhakṛd bhavet //

 *(vedhabhedāḥ)* 
lepavedhastathā kṣepaḥ kuṃtavedhastathaiva ca //

dhūmākhyaḥ śabdavedhaḥ syād evaṃ pañcavidhaḥ smṛtaḥ *(lepavedha)*  
sūkṣmāṇi tāmrapatrāṇi kaladhūtabhavāni ca  
kalkena lepitānyeva dhmāpayed andhamūṣayā //

śītībhūte tamuttārya lepavedhaśca kathyate *(kṣepavedha)*  
drute tāmre 'thavā raupye rasaṃ tatra vinikṣipet //

vidhyate tena sahasā kṣepavedhaḥ sa kathyate *(kuntavedha)*  
drāvayennāgarūpyaṃ ca tāmraṃ caiva tathāvarān //

pārado 'nyatame pātre drāvite 'tra niyojitaḥ  
vedhate kuntavedhaḥ syād iti śāstravido 'bruvan //

 *(dhūmavedha)* 
dhūmasparśena jāyante dhātavo hemarūpyakau  
dhūmavedhaḥ sa vijñeyo rasarājasya niścitam //

 *(śabdavedha)* 
baddhe rasavare sākṣāt sparśanājjāyate ravaḥ  
tathaiva jāyate vedhaḥ śabdavedhaḥ sa kathyate //

 *(17. rañjana)* 
athedānīṃ pravakṣyāmi raṃjanaṃ pāradasya hi  
rañjitaḥ krāmitaścaiva sākṣāddevo maheśvaraḥ //

raṃjanaṃ lohatāmrābhyāṃ rasakena vidhīyate  
tathā raktagaṇenaiva kartavyaṃ śāstravartmanā //

gandharāgeṇa kartavyaṃ pāradasyātha raṃjanam  
tāmreṇa raktakācena raktasaindhavakena ca //

aṃdhamūṣāgataṃ sūtaṃ rañjayettāmrakādibhiḥ  
iṣṭikāyantrayogena gandharāgeṇa rañjayet //

rasakasya ca rāgeṇa tulāyantrasya yogataḥ *(mercury:: rañjana)*  
mardanāttīkṣṇacūrṇena rañjayetsūtakaṃ sadā //

 *(mercury:: rañjana)* 
tāmrakalkīkṛtenaiva sthāpayetsaptavāsaram  
raṃjanaṃ sūtarājasya jāyate nātra saṃśayaḥ //

 *(mercury:: rañjana)* 
mṛṇmūṣā ca prakartavyā raktavargeṇa lepitā  
tanmadhye pāradaṃ kṣiptvā dhmānād rañjanakaṃ bhavet //

mayā saṃkṣepataḥ proktaṃ raṃjanaṃ pāradasya hi  
śāstramārgeṇa bahudhā raṃjanaṃ hi nidarśitam //

 *(18. sevana)* 
atha sevanakaṃ karma pāradasya daśāṣṭamam  
kathyate 'tra prayatnena vistareṇa mayādhunā //

yatnena sevitaḥ sūtaḥ śāstramārgeṇa siddhidaḥ  
anyathā bhakṣitaścaiva viṣavanmārayennaram //

ādau tu vamanaṃ kṛtvā paścādrecanamācaret  
tato mṛtābhraṃ bhakṣeta paścātsūtasya sevanam //

samyak sūtavaraḥ śuddho dehalohakaraḥ sadā  
sevitaḥ sarvarogaghnaḥ sarvasiddhikaro bhavet //

yāvanmānena lohasya gadyāṇe vedhakṛdbhavet  
tāvanmānena dehasya bhakṣito rogahā bhavet //

rājikātha priyaṃguśca sarṣapo mudgamāṣakau  
raktikā caṇako vātha vallamātro bhavedrasaḥ //

eṣā mātrā rase proktā sarvakarmaviśāradaiḥ  
anupānena bhuñjīta parṇakhaṇḍikayā saha //

itthaṃ saṃsevite sūte sarvarogādvimucyate  
sarvapāpādvinirmuktaḥ prāpnoti paramāṃ gatim //

### YRps, Adhyāya 2

 *(pāradabandha)* 
athedānīṃ pravakṣyāmi rasarājasya baṃdhanam  
anubhūtaṃ mayā kiṃcit gurūṇāṃ hi prasādataḥ //

 *(bandhana:: subtypes)* 
baṃdhaścaturvidhaḥ prokto jalaukā khoṭapāṭakau  
tathā bhasmābhidhaḥ sākṣāt kathito'pi rasāgame //

pakvabandho jalaukā syāt piṣṭīstambhastu khoṭakaḥ  
pāṭaḥ parpaṭikābandho bhasma bhūtisamo bhavet //

 *(substances inducing bandhana)* 
mūlikātra maṇiścaiva svarṇakaṃ nāgavaṅgake  
catvāra ete sūtasya bandhanasyātha kāraṇam //

uttamo mūlikābandho maṇibandhastu madhyamaḥ  
adhamo dhātubandhastu pūtibandho 'dhamādhamaḥ //

drutibandhaḥ pañcamo'sau dehalohakaraḥ sadā  
abhradrutiviśeṣeṇa vijñeyo'sau bhiṣagvaraiḥ //

 *(mūlikābandha)* 
kramaprāptamidaṃ vakṣye mūlikābandhanaṃ rase  
śuddho rākṣasavaktraśca rasaścābhrakajāritaḥ //

iṅgudīmūlaniryāse marditaḥ pāradastryaham  
tata uddhṛtya vastreṇa baṃdhanaṃ kārayed bhiṣak //

kāṃjike svedanaṃ kuryān niyataṃ saptavāsaram  
pācitaṃ cānnamadhye tu kartavyaṃ vatsarāvadhi //

tato dhūrtaphale nyastaṃ svedayecchatasaṃkhyayā  
pācito'sau mahātaile dhūrtataile 'nnarāśike //

baddhastu tena vidhinā kaṭhinatvaṃ prajāyate  
vaṃgasya stambhanaṃ samyak karotyeva na saṃśayaḥ //

dhārito'sau mukhe sākṣād vīryastambhakaraḥ sadā  
mūlikābaṃdhanaṃ hyekaṃ kathitaṃ pāradasya vai //

 *(mūlikābandha (2))* 
athāparaḥ prakāro hi bandhanasyāpi pārade  
nāgārjunīmūlarasair mardayed dinasaptakam //

mukhacarvaṇasambhūtair nimbakāṣṭhena peṣitaḥ  
navanītasamas tena jāyate pāradastataḥ //

vastreṇa baṃdhanaṃ kṛtvā phale dhaurte niveśayet  
gomayairveṣṭitaṃ tacca karīṣāgnau vipācayet //

lāvakākhye puṭe samyak kramavṛddhyā śataṃ puṭet  
māsatrayapramāṇena pācayedannamadhyataḥ //

paścātpuṭaśataṃ dadyāc chagaṇenātha pūrvavat  
anenaiva prakāreṇa badhyate sūtakaḥ sadā //

dṛṣṭapratyayayogo'yaṃ kathitaḥ sādhakāya vai  
dhārito'sau mukhe samyak vīryastaṃbhakaraḥ param  
vaṃgastaṃbhakaro'pyevaṃ baddhaḥ sūtavaro'pyalam //

 *(mūlikābandha)* 
śuddhaṃ sujāritābhraṃ vai sūtakaṃ ca vimardayet  
arkamūlarasenaiva vāsaraikaṃ prayatnataḥ //

vajramūṣā tataḥ kāryā sudṛḍhā masṛṇīkṛtā  
arkamūlabhavenaiva kalkena parilepitā //

mūṣāmadhye rasaṃ muktvā cāndhayed anyamūṣayā  
yāmārdhaṃ dhmāpitaḥ samyak rasakhoṭaḥ prajāyate //

svāṃgaśītaṃ parijñāya rasakhoṭaṃ samuddharet  
varṣamātraṃ dhṛto vaktre valīpalitanāśanaḥ //

sarvasiddhikaro'pyeṣa mūlikābaddhapāradaḥ  
mūlikābaṃdhanaṃ satyaṃ kṛtaṃ nāgārjunādibhiḥ //

sarvasiddhikaraṃ śreṣṭhaṃ sarvakāryakaraṃ sadā //

 *(mūlikābandha (4))* 
śuddhaṃ rasavaraṃ samyak tathaivāmbarabhakṣitam  
jalakūmbhīrasaiḥ paścān mardayeddinasaptakam //

tasyāḥ prakalpayenmūṣāṃ sūtakaṃ tatra nikṣipet  
anyasyāmandhamūṣāyāṃ sūtamūṣāṃ nirundhayet //

puṭaṃ tatra pradātavyaṃ ekenāraṇyakena ca  
puṭānyevaṃ pradeyāni ekaikotpalavṛddhitaḥ //

anenaiva prakāreṇa puṭāni trīṇi dāpayet  
bandhamāpnoti sūtendraḥ satyaṃ guruvaco yathā //

 *(mūlikābandha (5))* 
cūrṇīkṛtāni satataṃ dhūrtabījāni yatnataḥ  
sūtarājasamānyevam ūrdhvayantreṇa pātayet //

ekaviṃśativārāṇi tataḥ khalve nidhāpayet  
iṅgudīpatraniryāse mardayeddinasaptakam //

bhṛṃgarājarasenaiva viṣakharparakena ca  
pāṭhārasena saṃmardya lajjālusvarasena vai //

tryahaṃ tryahaṃ ca saṃmardya bandhamāyāti niścitam  
dolāyaṃtreṇa saṃsvedya saptāhaṃ dhūrtaje rase //

viṣamūṣodare dhṛtvā māṃse sūkarasaṃbhave  
bharjayeddhūrtatailena saptāhājjāyate mukham //

kaṭhino vajrasadṛśo jāyate nātra saṃśayaḥ  
kṣīraṃ śoṣayate nityaṃ kautukārthe na saṃśayaḥ //

vīryaṃ vaṃgaṃ stambhayati satyaṃ satyaṃ na saṃśayaḥ  
prakārāḥ kathitāḥ pañca sūtarājasya baṃdhane //

 *(vajrasattvena śatavedhī rasabandhaḥ (1))* 
vajrabaṃdhaṃ dvitīyaṃ tu krameṇaiva yathātatham  
rasaśāstrāṇi bahudhā nirīkṣya pravadāmyaham //

vajrasatvaṃ tathā sūtaṃ samāṃśaṃ kārayed budhaḥ  
rasapādasamaṃ hema trayamekatra mardayet //

vaṃdhyākarkoṭikāmūlarasenaivātha bhāvayet  
tathā dhūrtarasenāpi citrakasya rasena vai //

kāmbojīrasakenāpi tathā nāḍīrasena vai  
āsāṃ niyāmikānāṃ ca rasaṃ vastreṇa gālayet //

sūryātape dinaikaikaṃ krameṇānena mardayet  
aṃdhamūṣāgataṃ golaṃ mudrayeddṛḍhamudrayā //

lohasaṃpuṭake paścān nikṣiptaṃ mudritaṃ dṛḍham  
ghaṭikādvayamānena dhmāpitaṃ bhastrayā khalu //

svāṃgaśītalakaṃ jñātvā gṛhṇīyātāṃ ca mūṣikām  
utkhanyotkhanya yatnena sūtabhasma samāharet //

kācaṭaṃkaṇayogena dhmāpitaṃ taṃ ca golakam  
vedhate śatavedhena sūtako nātra saṃśayaḥ //

vaktrastho nidhanaṃ hanyād dehalohakaro bhavet //

 *(vajrabhasmayogena rasabandhaḥ (7))* 
vajrabhasma tathā sūtaṃ samaṃ kṛtvā tu mardayet  
trinemikāvajravallīsahadevīrasena ca //

snuhikṣīreṇa saptāhaṃ sūryagharme sutīvrake  
rasagolaṃ suvṛttaṃ tu śuṣkaṃ caivātha lepayet //

kākamācīrasenaiva lāṃgalīsvarasena hi  
gojihvikārasenaiva saptavāraṃ pralepayet //

vajramūṣāgataṃ golaṃ mudrayeddṛḍhamudrayā  
lohasaṃpuṭamūṣāyām andhitaṃ madhyasaṃsthitam //

saptamṛtkarpaṭaiḥ samyag lepitaṃ sudṛḍhaṃ kuru  
dhmāpitaṃ dṛḍhamaṃgārais tatrasthaṃ śītalīkṛtam //

bhittvā mūṣāgataṃ sūtaṃ khoṭaṃ nakṣatrasannibham  
sarvakāryakaraṃ śubhraṃ rañjitaṃ vedhakṛdbhavet //

 *(abhradrutyā rasabandhaḥ (8))* 
abhrakadrutibhiḥ sārdhaṃ sūtakaṃ ca vimardayet  
samāṃśena śilāpṛṣṭhe yāmatrayamanāratam //

kastūrīdhanasārābhyāṃ kṛṣṇāgarusamanvitam  
śarkarālaśunābhyāṃ ca rāmaṭhena ca saṃyutam //

palāśabījasya tathā tatprasūnarasena hi  
tīkṣṇāṃśunātha mṛditaṃ drutibhiḥ saha sūtakam //

milatyeva na saṃdehaḥ kimanyair bahubhāṣitaiḥ  
tato guñjārasenaiva śvetavṛścīvakasya ca //

lāṃgalyāśca rasaistāvad yāvadbhavati bandhanam //

tataḥ prakāśamūṣāyāṃ pañcāṃgārairdhametkṣaṇam  
bandhamāyāti vegena yathā sūryodaye 'mbujam //

abhradrutisamāyoge rasendro vadhyate khalu  
śivabhakto bhavetsākṣāt satyavāk saṃyatendriyaḥ //

śivayormelanaṃ samyak tasya haste bhaviṣyati  
rasāgameṣu yatproktaṃ baṃdhanaṃ pāradasya ca //

kathitaṃ tanmayā spaṣṭaṃ nānubhūtaṃ na ceṣṭitam //

 *(vajradrutyā rasabandhaḥ (9))* 
vajrāṇāṃ brahmajātīnāṃ drutirvallapramāṇikā  
tolakaṃ śuddhasūtaṃ ca mardayetkanyakārase //

tāvattaṃ mardayetsamyag yāvat piṣṭī prajāyate  
kṛtvā mūṣāṃ samāṃ śuddhāṃ dahanopalanirmitām //

tanmadhye piṣṭikāṃ muktvā piṣṭīmānaṃ viṣaṃ tvaheḥ  
pidhānaṃ tādṛśaṃ kuryān mukhaṃ tenātha rundhayet //

kāṃsyabhājanamadhye tu sthāpayenmūṣikāṃ śubhām  
bhājanāni ca catvāri caturdikṣu gatāni ca //

citraṃ gharmaprasaṃgena bandhamāyāti pāradaḥ  
yāmātkharātape nityaṃ śivenoktam atisphuṭam //

vajradrutisamāyogāt sūto bandhanakaṃ vrajet  
sarveṣāṃ sūtabandhānāṃ śreṣṭhaṃ satyamudīritam //

 *(suvarṇadrutyā rasabandhaḥ (10))* 
athedānīṃ pravakṣyāmi sūtarājasya bandhanam  
hemadrutiṃ rasendreṇa mardayetsaptavāsarān //

jvālāmukhīrasenaiva dhautaḥ paścācca kāṃjikaiḥ  
pratyahaṃ kṣālayedrātrau rasenoktena vai divā //

aṃdhamūṣāgataṃ paścān mṛdā karpaṭayogataḥ  
lepayetsaptavārāṇi bhūgarte golakaṃ nyaset //

dvādaśāṃgulavistīrṇaṃ dvādaśāṃgulanimnakam  
khātapramāṇaṃ kathitaṃ gurumārgeṇa ca sphuṭam //

tatropari puṭaṃ deyaṃ gajāhvaṃ chagaṇena ca  
yāmadvādaśakenaiva badhyate pāradaḥ svayam //

hemadrutau baddharaso dehalohaprasādhakaḥ  
sarvasiddhikaraḥ śrīmān jarādāridryanāśanaḥ //

 *(suvarṇena rasabandhaḥ)* 
dhātubandhastṛtīyo'sau svahastena kṛto mayā  
tadahaṃ kathayiṣyāmi sādhakārthe yathātatham //

bhūrjavatsūkṣmapatrāṇi kārayetkanakasya ca  
tānyeva kolamātrāṇi palamātraṃ tu sūtakam //

mardayennimbukadrāvair dinamekamanāratam  
tatastadgolakaṃ kṛtvā kharparopari vinyaset //

culyāmāropaṇaṃ kāryaṃ dhānyāmlena niṣiñcayet  
piṣṭistaṃbhastu kartavyo niyataṃ tridināvadhi //

tato dhūrtarasenaiva svedayetsaptavāsarān  
śvetā punarnavā ciṃcā sahadevī ca nīlikā //

tathā dhūrtavadhūś caiva lāṃgalī suradālikā  
sūtabandhakarā śreṣṭhā proktā nāgārjunādibhiḥ //

etāsāṃ svarasaiḥ paṅkair lepayetsūtagolakam  
triguṇair bhūrjapatraistu veṣṭayettadanaṃtaram //

vastreṇa poṭalīṃ baddhvā svedayenniṃbukadravaiḥ  
yāmatrayaṃ prayatnena dhautaḥ paścād gavāṃ jalaiḥ //

tato dhūrtaphalāntasthaṃ pācayedbahubhiḥ puṭaiḥ  
lāvakākhyaiḥ sumatimān śobhanaḥ sūryakāntivat  
jāyate nātra saṃdeho baddhaḥ śivasamo bhavet //

 *(raupyeṇa rasabandhaḥ)* 
aṣṭamāṃśena rūpyena sūtakaṃ hi pramardayet  
cāṃgerīsvarasenaiva piṣṭikāṃ kārayed budhaḥ //

khoṭaṃ baddhvā tu vipacet dhūrtataile trivāsarān  
tathā ca kaṃguṇītaile karavīrajaṭodbhave //

jātīphalodbhavenāpi vatsanāgodbhavena ca  
bhṛṃgyudbhavena ca tathā samudraśoṣakasya vai //

devadārubhavenāpi pācayenmatimān bhiṣak  
paścātsutīkṣṇamadirā dātavyā tu tuṣāgninā //

dināni saptasaṃkhyāni mukham utpadyate dhruvam  
śukrastambhakaraḥ samyak kṣīraṃ pibati nānyathā //

 *(tutthena tutthotthatāmreṇa rasabandhaḥ)* 
lohapātre suvistīrṇe tutthakasyālavālakam  
aṣṭasaṃskāritaṃ sūtaṃ tasminnikṣipya mātrayā //

tutthacūrṇena saṃchādya pūrayennimbukadravaiḥ  
pidhānena mukhaṃ ruddhvā lohapātrasya yatnataḥ //

nirvāte nirjane deśe tridinaṃ sthāpayettataḥ  
uṣṇakāṃjikayogena kṣālayed bahuśo bhiṣak //

navanītasamo varṇaḥ sūtakasyāpi dṛśyate  
rasakhoṭaṃ tato baddhvā svedayetkāṃjikaistryaham //

aśmacūrṇasya kaṇikāmadhye khoṭaṃ nidhāya ca  
jalasekaḥ prakartavyaḥ śītībhūtaṃ samuddharet //

anenaiva prakāreṇa trivāraṃ pācayed dhruvam  
kaṭhinatvaṃ prayātyeva satyaṃ guruvaco yathā //

tato dhūrtaphalānāṃ hi sahasreṇāpi pācayet  
mukham utpadyate samyak vīryastaṃbhakaro 'pyayam //

 *(dhātubījena rasabandhaḥ)* 
vaṃgatīkṣṇe same kṛtvā dhmāpayedvajramūṣayā  
vaṅgam uttārayetsamyak tīvrāṅgāraiḥ prayatnataḥ //

anenaiva prakāreṇa triguṇaṃ vāhayettrapu  
bījaṃ śāṇapramāṇaṃ hi sūtaṃ palamitaṃ bhavet //

mardayetkanyakādrāvair dinamekaṃ viśoṣayet  
golasya svedanaṃ kāryam ahobhiḥ saptabhistathā //

triphalākvāthamadhye tu triyāmaṃ svedayetsudhīḥ

 *(mahauṣadhyaḥ)*

kekicūḍājagandhā ca lakṣmaṇā taruṇīti ca  
aṣṭaṣaṣṭiriti proktā mahauṣadhyo mahābalāḥ //

 *(siddhauṣadhyaḥ)*

adhaḥpuṣpī madhurākhyā śṛṅkhalā gṛñjanīti ca //

jārāvalī mahārāṣṭrī sahadeveśvarī tathā  
kāṣṭhagodhāmatī devagāndhārī rajanīṅgudī //

palāśinī nākulī ca kāmbojikāśvinī tathā  
cakravallī sarpadaṃṣṭrā śallakī rohitā tathā //

tauvarī vaṅgajā rājapadmā jambīravallikā  
gajapippalikā bhṛṃgavallī caivārkavallikā //

jantukārī śigruvallī karavīrā śivāṭikā  
nārācī kāñcanī cājagandhā sūtendrasiddhidāḥ //

aṣṭaṣaṣṭiriti proktāḥ siddhauṣadhyo rasādhikāḥ  
sarvakāryakarā dehalohasiddhipradāyakāḥ //

### YRps, Adhyāya 11

athātaḥ sampravakṣyāmi dhātūnāṃ kautukaṃ paraṃ  
svānubhūtaṃ mayā kiṃcit śrutaṃ vā śāstrataḥ khalu

 *(hemakaraṇavidhiḥ (2))*

navasārastathā sūtaḥ śodhito'gnisahaḥ khalu //

mātaluṃgarasenaiva kumārīsvarasena ca //

dināni trīṇi tīvrāgnau tatastadavatārayet //

vedavarṇāstu saṃgharṣād vardhante nātra saṃśayaḥ //

 *(hemakaraṇavidhiḥ (15))* 
ghoṣākṛṣṭaṃ tu yattāmraṃ rajatena samanvitam  
tīkṣṇacūrṇaṃ sadaradaṃ ghṛṣṭaṃ kanyārasena vai //

paścādvidheyā guṭikāḥ sūkṣmāścaivāḍhakīsamāḥ  
vāpitā drāvite dravye sarvaṃ tāmraṃ tu saṃkṣipet //

rūpyamānaṃ samuttārya samahemnā ca gālayet  
jāyate daśavarṇaṃ tu satyametadudīritam //

 *(hemakaraṇavidhiḥ (16))* 
tāmre saptaguṇaṃ nāgaṃ vāhitaṃ punareva hi  
tena tāmreṇa rasakaṃ saptavāraṃ ca vāhayet //

svarṇavarṇaṃ hi tattāmraṃ jāyate nātra saṃśayaḥ //

 *(hemakaraṇavidhiḥ (17))* 
bhūnāgasattvamūṣāyāṃ drāvayetsvarṇamuttamam  
tāpyasatvena saṃyuktaṃ śatavāraṃ punaḥ punaḥ  
japāpuṣpanibhaṃ svarṇaṃ jāyate nātra saṃśayaḥ //

 *(hemakaraṇavidhiḥ (18))* 
daśavarṇasya gadyāṇe raktaṃ taddhemavallakam  
dvau varṇau vardhataḥ samyak haṭṭavikrayayogyakam //

 *(hemakaraṇavidhiḥ (19))* 
puṣpakāsīsakaṃ ramyaṃ mardayedarkapatraje /  
rase'tha ca cakrikāṃ kuryādrasakasya palonmitām //

veṣṭitāṃ pūrvakalkena ravigharmeṇa śoṣayet  
triṃśadvanopalaiḥ samyak puṭānyevaṃ hi viṃśatiḥ //

ṣoḍaśāṃśena rajataṃ vidhyate nātra saṃśayaḥ  
saptavarṇasavarṇaṃ hi jāyate nātra saṃśayaḥ //

 *(hemakaraṇavidhiḥ (20))* 
sūtako dvipalaḥ kāryaḥ sumbilaśca catuṣpalaḥ  
catuṣṭaṃkamitā kāryā sphaṭikī nirmalā śubhā //

vṛścikālīrase ghṛṣṭā dinam ekaṃ tu vārtikaiḥ  
paścācca śoṣayetsarvaṃ yantre ḍamaruke nyaset //

gairikaṃ sthāpayetpūrvaṃ khaṭikāṃ ca tathopari  
tanmadhye gartakaṃ kṛtvā gartake navasādaram //

ṭaṅkamānaṃ prakartavyaṃ tasyopari ca sūtakam  
sūtakopari sāraṃ hi pūrvoktaṃ ṭaṃkamānakam //

mudrāṃ kṛtvā śoṣayitvā paścāccullyāṃ niveśayet  
agniṃ kuryātprayatnena yāmaṣoḍaśamātrakaṃ //

svāṃgaśītaṃ samuttārya ūrdhvalagnaṃ tu grāhayet  
paścāt khalve nidhāyātha vṛścikālyā pramardayet //

kācakūpyāṃ kṣipet sarvaṃ kūpīṃ vālukāyantrake  
vahniṃ dvādaśabhiryāmaiḥ kuryācchītaṃ samāharet //

vallamātraṃ tato dadyāt sārdhaṭaṅke sutāmrake  
dṛṣṭapratyayayogo'yaṃ nāthasundarabhāṣitaḥ //

 *(raupyakaraṇavidhiḥ (1))* 
lohacūrṇaṃ palamitaṃ sumalakṣāram abhrakam  
ṭaṃkaṇaṃ śāṇamānaṃ hi tailenairaṇḍajena vai //

gharṣayedvaṭikāyugmaṃ golaṃ kṛtvā dhamettataḥ  
bhastrayā dhmāpayetsamyak lohaṃ rasanibhaṃ bhavet //

tallohaṃ triguṇaṃ caiva rasakaṃ kārayetsudhīḥ  
lohaṃ ca rasakaṃ paścād gālitaṃ vajramūṣayā //

lohaśeṣaṃ samuttārya tāmre dadyācca vallakam  
gadyāṇake bhavettāraṃ tattāraṃ śuddhatārake //

ardhabhāge bhavecchuddhaṃ tāraṃ doṣavivarjitam //

 *(raupyakaraṇavidhiḥ (2))* 
khaṇḍaṃ karṣapramāṇaṃ hi sumalakṣārakasya hi  
veṣṭitaṃ narakeśena drute nāge nimajjitam //

nirvāpitaṃ nimbujale caikaviṃśativārakam  
drute śulvasya gadyāṇe raktikāpañcamātrakam //

kalkaṃ dadyātprayatnena tāravarṇaṃ prajāyate  
gadyāṇe caturo vallān rūpyaṃ dattvā pragālayet  
jāyate ruciraṃ tāraṃ satyam etadudīritam //

 *(raupyakaraṇavidhiḥ (3))* 
śaṃkhaṃ sumbalanāmānaṃ palānyaṣṭau prakalpayet  
gojihvārasasaṃmiśraṃ dinamekaṃ pramardayet //

nimbūrasena dhūrtena kākamācīrasena vai  
gṛṃjanasya rasenaiva dinamekaṃ pramardayet //

arkadugdhena vai bhāvyaṃ tailenairaṇḍajena ca  
yavamātrāṃ guṭīṃ kṛtvā viśoṣya cātape khare //

kācakūpyāṃ vinikṣipya mudrayetkūpikāmukhaṃ  
saṃsthāpya vālukāyantre pacetṣoḍaśayāmakam //

svāṃgaśītaṃ samuttārya grāhyaṃ satvaṃ tad ūrdhvagam  
sattvaṃ gadyāṇamekaṃ tu tanmātraṃ tārasaṃpuṭam //

sūtaṃ gadyāṇakaṃ svacchaṃ ṭaṃkaṇaṃ vallapañcakam  
sūtamātraṃ kṣārasattvaṃ sarvaṃ caikatra marditam //

svarasena tu ketakyā golaṃ kṛtvā viśoṣitam  
tārasaṃpuṭamadhye tu dhāritaṃ taṃ ca golakam //

paścāttāmrakṛtāṃ mūṣām aṣṭavallamitāṃ śubhām /  
śarāvasaṃpuṭasyāntardhārayettadanaṃtaram //

dhānyābhraṃ tulyaṃ paṃkena kṛtvā śrāvaṃ tu pūrayet /  
vārāhākhyapuṭaikena jāyate kalka uttamaḥ //

tāmraṃ dvādaśavallaṃ hi rūpyaṃ valladvayaṃ tathā  
vaṃgaṃ vallamitaṃ śuddhaṃ sarvamekatra gālayet //

caturguñjāpramāṇaṃ hi dāpayenmatimān bhiṣak  
jāyate pravaraṃ tāraṃ satyam etad udīritam //

 *(raupyakaraṇavidhiḥ (4))* 
asthibhakṣamalabaṃgamāritaṃ tālakābhraviṣasūtaṭaṃkaṇam  
vajribhānupayasā subhāvitaṃ syānnarendra śubhatāraparvatam //

 *(raupyakaraṇavidhiḥ (5))* 
vaṃgaṃ tālakamabhrakaṃ śaśirasaṃ tīkṣṇaṃ viṣaṃ ṭaṃkaṇaṃ /  
traivāreṇa ca mūkamūṣadhamitaṃ vindanti candraprabham //

āraṃ dvādaśabhāgamaṣṭaraviṇo bījaṃ caturthāṃśakam /  
bhūgaṇḍādisamastadoṣarahitaṃ śrīpūjyapādoditam //

 *(raupyakaraṇavidhiḥ (6))* 
pāradasya trayo bhāgā bhāgaikaṃ rajatasya hi  
nimbūrasena saṃmardya piṣṭīṃ kṛtvā prayatnataḥ //

kāṃjikena tu tāṃ piṣṭīṃ stambhayedvāsaratrayam  
sārayedbaṃgamadhye tu sūtakaṃ tadanaṃtaram //

sāritaṃ sūtakaṃ tena tālasattvena sādhayet  
tena vedhyaṃ drutaṃ tāmraṃ ṣoḍaśāṃśena yatnataḥ //

jāyate pravaraṃ tāraṃ caṃdranakṣatrasannibham //

 *(raupyakaraṇavidhiḥ (7))* 
sūtakasya trayo bhāgā baṃgaṃ bhāgadvayaṃ tathā  
mardayeddinamekaṃ tu kāṃjikena samanvitam //

sarvebhyastriguṇenātha sumbalena pramardayet  
snuhyarkadugdhena samaṃ bhāvayedvāsaratrayam //

yavapramāṇāṃ guṭikāṃ ravitāpena śoṣitām  
kācakūpyāṃ nidhāyātha vahniṃ kuryātprayatnataḥ //

yāmaṣoḍaśaparyaṃtaṃ vālukāyaṃtrake pacet  
svāṃgaśītaṃ samuddhṛtya cordhvagaṃ satvamāharet //

ṣoḍaśāṃśena śulbaṃ hi kuntavedhena vedhayet  
jāyate pravaraṃ tāraṃ haṭṭavikrayayogyakam //

 *(raupyakaraṇavidhiḥ (8))* 
palāṣṭamātraṃ tālaṃ tu dvikarṣapramitaṃ rasam  
nimbūrasena saṃmardyaṃ vāsaraikaṃ prayatnataḥ //

paścāttaṃ mardayeddhīmān tailenairaṇḍajena vai  
vālukāyantramadhyasthaṃ pacedyāmāṃstu ṣoḍaśa //

paścātsattvaṃ samuddhṛtya mardayedekavāsaram  
atasītilatailena kācakūpyāṃ nidhāpayet //

pūrvavatpācayed vahnau svāṃgaśītaṃ samuddharet  
anenaiva prakāreṇa punarevaṃ tu kārayet //

kūpītalasthitaṃ sattvaṃ grāhyaṃ cetpravaraṃ sadā  
ṣoḍaśāṃśena śulbasya vedhaṃ kuryānna saṃśayaḥ //

 *(raupyakaraṇavidhiḥ (9))* 
pāradaṃ ṭaṃkamānaṃ tu lavaṇaṃ dviguṇaṃ tathā  
khalve vimardayettāvad yāvannaṣṭo raso bhavet //

tāmraṃ gadyāṇakaṃ śuddhaṃ baṃgaṃ vallamitaṃ kuru  
drute tāmre'tha lavaṇaṃ sūtakena samanvitam //

māṣamātraṃ pradātavyaṃ caturthāṃśena rūpyakam  
tadrūpye marditaṃ sūtaṃ kṣeptavyaṃ jalayantrake //

tattrayodaśakaṃ rūpyaṃ jāyate nātra saṃśayaḥ //

 *(raupyakaraṇavidhiḥ (10))* 
tālena nihataṃ baṃgaṃ tadbaṃgena tu rūpyakam  
pacedyāmāṣṭakaṃ samyak kalka evaṃ prajāyate  
vallaṃ gadyāṇake dadyād baṃgaṃ stambhayate dhruvam //

 *(raupyakaraṇavidhiḥ (11))* 
daradaṃ khaṇḍaśaḥ kṛtvā ṭaṃkatrayamitaṃ pṛthak  
vajrīkṣīreṇa tatsvedyaṃ dolāyaṃtreṇa vārtikaiḥ //

tāracūrṇaṃ samaṃ lepyaṃ luṅgatoyasamaṃ tathā  
govaraiḥ pācayetsvalpam eva dvādaśayāmakam //

piṣṭistambho bhavettena paścāttārarajaḥ pṛthak  
kuryāddaradakhaṇḍena samaṃ sīsaṃ ca dāpayet //

gālayenmūṣikāmadhye śītaṃ kṛtvā tu khoṭakam  
bhasma mūṣopari nyasya dhmāpayecca śanaiḥ śanaiḥ //

śuddhaśaṅkhanibhaṃ rūpyaṃ niṣkamātraṃ hi niḥsaret //

 *(raupyakaraṇavidhiḥ (12))* 
dvipalaṃ śuddhasūtaṃ ca dvipalaṃ rasakasya ca  
tālakaṃ ca paladvaṃdvaṃ surmilaṃ yugmamātrakam //

kūpyāmāropayetsarvaṃ mukhaṃ tāmreṇa rundhayet  
vālukāyantrake samyak paced dvādaśayāmakam //

kūpīmukhe tu yallagnaṃ sattvaṃ grāhyaṃ prayatnataḥ  
śulbe ṣoḍaśavedhena kārayedrajataṃ varam //

 *(raupyakaraṇavidhiḥ (13))* 
sūtakaṃ palamekaṃ tu śaṃkhābhaṃ surmilaṃ palam  
eraṇḍataile ghṛṣṭaṃ tad dhāritaṃ kharpare vare //

andhitaṃ tāmrapātreṇa mudritaṃ sudṛḍhaṃ kṛtam  
paścāccullyāṃ samāropya vahniṃ kuryācchanaiḥ śanaiḥ //

sārdhaṃ yāmaṃ tataḥ pācyaṃ svāṃgaśītaṃ samuddharet  
tāmrapātre tu yallagnaṃ sarvaṃ sattvaṃ samāharet //

ghṛtāktaṃ ṭaṃkaṇopetaṃ gālitaṃ mūṣikāmukhe  
deyaṃ tadvallamātraṃ hi drute tāmre tu sattvakam //

śaṃkhābhaṃ jāyate tāraṃ nātra kāryā vicāraṇā //

 *(raupyakaraṇavidhiḥ (14))* 
tālaṃ tāmraṃ rītighoṣaṃ samāṃśaṃ kuryādevaṃ gālitaṃ ḍhālitaṃ hi  
amle varge saptavāraṃ praḍhālya paścādyojyaṃ tulyabhāge ca rūpye  
śuddhaṃ rūpyaṃ ṣoḍaśākhyaṃ hi samyak jātaṃ dṛṣṭaṃ nānṛtaṃ satyametat //

 *(raupyakaraṇavidhiḥ (15))* 
śvetaṃ sauvīrakaṃ śuddhaṃ pācitaṃ viṣamuṣṭinā  
svacche sūtavare vallaṃ nikṣiptaṃ rūpyakṛdbhavet //

 *(raupyakaraṇavidhiḥ (16))* 
śuddhasphaṭikasaṃkāśaṃ surmilaṃ dṛśyate kvacit  
mṛtkharpare pācitaṃ hi nimbūkadravasaṃyutam //

ghaṭikādvayamānena śuddhakalkaḥ prajāyate  
catuḥṣaṣṭyaṃśamānena vedhayecchulbakaṃ śubham //

jāyate pravaraṃ tāraṃ sarvadoṣavivarjitam //

 *(raupyakaraṇavidhiḥ (17))* 
saptadhātumayī mūṣā kṣārabhasmaprapūritā  
kadalyāḥ kṣārakeṇaiva tathāpāmārgasaṃbhavaiḥ //

madhye pāradakaṃ muktvā punarevaṃ prapūrayet  
anena vidhinā pūryā dvitīyā mūṣikā śubhā //

mudritavyā prayatnena govare puṭake nyaset  
sūtakaṃ bandham āyāti vaṅgābhaṃ tu prajāyate  
drutadrāvaṃ ghātasahaṃ dṛṣṭamevaṃ mayā khalu //

 *(kṛtrimamauktikakaraṇam)* 
netrāṇyāhṛtya matsyānāṃ paktvā dugdhena yāmakam  
paścādākṛṣṇakaṇakān ākṛṣya kila kaṇḍayet //

tāni śālisametāni tāvacchubhrāṇi kārayet  
paścādiṣṭikacūrṇena haste kṛtvā pramardayet //

mauktikāni hi jāyante kṛtānyevaṃ mayā khalu //

 *(sūkṣmamauktikebhyo bṛhanmauktikakaraṇam)* 
mūṣikāṃ kārayecchuddhāṃ sphāṭikīṃ dahanopalām  
mauktikāni tu sūkṣmāṇi nimbūdrāve nidhāpayet //

ahorātreṇa sarvāṇi navanītasamāni ca  
tasya paṃkasya guṭikāṃ masṛṇāṃ tu prakārayet //

paścāttāṃ mūṣikāmadhye citrāgharme dviyāmakam  
catvāri kāṃsyabhāṇḍāni caturdikṣu gatāni ca //

arbhakāḥ pātayetsarvāḥ madhyabhājanakopari  
badhyate mauktikaṃ śreṣṭhataraṃ sarvaguṇairyutam //

 *(kṛtrimapravālakaraṇam)* 
śuddhaśaṅkhasya cūrṇaṃ hi sūkṣmaṃ kṛtvā prayatnataḥ  
ardhabhāgaṃ ca daradaṃ cūrṇayenmatimāṃstataḥ //

sadyaḥ sūtāvikakṣīraṃ tena dugdhena mardayet  
vartiṃ vidhāya matimān kārpāsāsthiṣu svedayet //

svāṃgaśītaṃ samuttārya pravālaṃ ruciraṃ bhavet //

### YRps, Adhyāya 12

 *(vānarī vaṭī)* 
ātmaguptāphalaṃ śuṣkaṃ nistuṣaṃ cāṣṭapālikam  
māṣasyāṣṭapalaṃ tadvaj jalena paripeṣitam //

ārdraṃ kṛtvobhayaṃ samyak śilāpaṭṭena peṣayet  
kuṃkumaṃ kesaraṃ caiva jātīpatraṃ śatāvarī //

gokṣurekṣurabījāni lavaṃgaṃ maricaṃ kaṇā  
śṛṅgāṭakaṃ karṣamitaṃ kuryādevaṃ pṛthak pṛthak //

sūkṣmacūrṇaṃ vidhāyātha pūrvapiṣṭe nidhāpayet  
vaṭakān kārayet paścāt karṣamātrān vipācayet //

ghṛtaprasthatrayeṇaiva sutalathya nimajjayet  
mākṣike ghṛtamāne vai mukhaṃ rundhyāddinatrayam //

madhvājyamiśritaṃ bhuñjyād ekaikaṃ vaṭakaṃ prage  
saptakāni ca pañcaivam āhāraṃ madhuraṃ bhajet //

dugdhaudanaṃ tathā rātrau kṣāramamlaṃ ca varjayet  
retaḥkṣayī tathā klībo gacchecca pramadāśatam //

aputraḥ putramāpnoti ṣaṇḍho'pi puruṣāyate  
dṛṣṭapratyayayogo'yaṃ satyametadudīritam //

 *(śatāvaryādivājīkaro 'valehaḥ (1))* 
śatāvarīṃ kṣīravidārikāṃ ca prasthārdhamānāṃ pṛthageva kuryāt  
rasaṃ tathā śālmalimadhyamūlāt prasthaṃ sitārdhāḍhakamatra deyam //

supācitaṃ vai mṛduvahninā tathā darvīpralepo'pi hi jāyate yathā /  
tvakpatrakailāḥ saha kesareṇa palapramāṇā hi tato vidadhyāt //

lehe suśīte madhu bilvamātraṃ prātaḥ prabhakṣediha karṣamātram //

 *(śṛṅgātakādivājīkaro 'valehaḥ (2))* 
śṛṅgāṭakasyāpi palaṃ vidheyaṃ vārāhikandaśca palapramāṇaḥ  
cūrṇīkṛtaṃ gālitameva vastrād bhṛṣṭaṃ tathājyena sitāsametam //

lavaṃgakṛṣṇāgarukeśarāṇāṃ palaṃ pradadyāddaśabhāgadugdham  
lehaṃ sujātaṃ khalu bhakṣayettat karṣapramāṇaṃ nitarāṃ prabhāte  
kāmasya bodhaṃ kurute hi śīghraṃ nārīṃ ramedvai caṭakāyate'sau //

 *(kāmadīptikaravājīkaro 'valehaḥ (3))* 
śatāvarīgokṣuradarbhamūlaṃ śṛṅgāṭakaṃ nāgabalātmagupte  
saṃcūrṇya sarvaṃ pṛthageva pālikaṃ kṣīreṇa pācyaṃ daśabhāgakena //

sitā pradeyā daśapālikātra pākaṃ vidadhyādapi cāgniyogāt  
madhuplutaṃ bhakṣitamardhayāmāt kāmapradīptiṃ kurute sadaiva //

vīryasya vṛddhiṃ jaṭharāgnivṛddhiṃ kāmāgnivṛddhiṃ sahasā karoti //

 *(māṣādivājīkaro 'valehaḥ (4))* 
māṣāṇāmātmaguptāyā bījānāmāḍhakaṃ navam  
jīvakarṣabhakau jīvāṃ medāṃ vṛddhiṃ śatāvarīm //

madhukaṃ cāśvagandhāṃ ca sādhayet prasṛtonmitām  
rase tasminghṛtaprasthaṃ gavyaṃ daśaguṇaṃ payaḥ //

vidārīsvarasaprasthaṃ prasthamikṣurasasya ca  
dattvā mṛdvagninā sādhyaṃ siddhasarpirnidhāpayet //

śarkarāyāstugākṣīryāḥ kṣaudrasya ca pṛthak pṛthak  
bhāgāṃścatuṣpalāṃstatra pippalyāścāvapetpalam //

palaṃ pūrvamito līḍhvā tato'nnam upayojayet  
yadīcchedakṣayaṃ śukraṃ śephasaścottamaṃ balam //

### YRps, Adhyāya 13

 *(vīryastambhakarī vaṭī)* 
śrīvāsamastakīnāgakesaraṃ ca lavaṃgakam  
kaṃkolaṃ tulasībījaṃ khurāsānyahīphenakam //

jāvitrikābdhiśoṣaṃ ca karabhāgurukuṃkumam  
kaṅkolakatugākṣīrījātīphalasamāṃśakān //

sarvāṇyevaṃ vicūrṇyātha nālikerodare kṣipet  
dugdhamadhye vipācyainaṃ dinānyevaṃ hi pañca ca //

nālikeraphalādgrāhyaṃ mardayenmadhunā saha  
guṭikā kolamātrā hi bhakṣaṇīyā niśāmukhe //

vīryastaṃbhaṃ karotyugraṃ caturyāmāvadhiṃ tathā //

 *(śukrastambhakarī vaṭī)* 
lavaṃgaṃ śuddhakarpūraṃ jātīpatraṃ phalaṃ tathā  
kuṅkumaṃ svarṇabījaṃ ca dhūrtaparṇaṃ prasūnakam //

mūlaṃ tvak cābdhiśoṣasya sarvāṇyekatra mardayet  
godugdhe śodhanīyaṃ ca bhāgamekaṃ prakalpayet //

bhṛṅgīpattrabhavaṃ cūrṇaṃ bhāgaikaṃ svarṇagairikam  
bhāvanāṃ postatoyena ekaviṃśatisaṃkhyayā //

kārayenmatimān vaidyaḥ śukrastaṃbhakarīṃ vaṭīm //

 *(retaḥstambhakarī vaṭī)* 
jātīphalārkakarahāṭalavaṅgaśuṇṭhīkaṅkolakeśarakaṇāharicandanāni etaiḥ samānamahiphenamanena cābhraṃ śvetaṃ nidhāya madhunā vaṭakān vidadhyāt  
māṣadvayonmitamamuṃ niśi bhakṣayitvā mṛṣṭaṃ payastadanu māhiṣamāśu pītvā kurvantu kāmukajanāḥ pratiruddhapātāścetāṃsi tāni cakitāni kalāvatīnām //

 *(vīryastambhakarī lepavaṭī)* 
skandhadeśācca saṃjātaṃ vīryaṃ dardurasaṃbhavam  
ghanasāreṇa saṃyuktaṃ karahāṭasya cūrṇakam //

saṃmardya kārayeccūrṇaṃ vaṭīṃ mudgapramāṇakām  
saṃgharṣya mukhatoyena liṃgalepaṃ prakārayet //

yāmārdhaṃ dhārayedbinduṃ satyaṃ guruvaco yathā //

 *(śukrastambhakacūrṇam)* 
postakaṃ palamekaṃ vai śuṃṭhīkarṣaḥ sitā palaikā ca /  
karṣamitā tvakpayasā pītaṃ reto dhruvaṃ dhatte //

śrīgaṅgādharabhaktisaktamanaso vidyāvinodāmbudheḥ śrīgoḍānvayapadmanābhasudhiyas tasyātmajenāpyayam  
sadvaidyena yaśodhareṇa kavinā vidvajjanānandakṛd grantho'yaṃ grathitaḥ karotu satataṃ saukhyaṃ satāṃ mānase //

deśānāṃ surarāṣṭram uttamatamaṃ tatrāpi jīrṇābhidhaḥ prākāro'sti sa vedaśāstraniratairvipraiśca saṃśobhitaḥ  
tasmin śaṃbhupadāravindaratikṛcchrīpadmanābhaḥ svayam tatputreṇa yaśodhareṇa kavinā graṃthaḥ svayaṃ nirmitaḥ //

saṃbodhāya satāṃ sukhāya sarujāṃ śiṣyārthasaṃsiddhaye vaidyānāmupajīvanāya viduṣām udveganāśāya vai  
śrīmaddurgapurātane 'tinipuṇaḥ śrīpadmanābhātmajaḥ śrīmadbhaṭṭayaśodharaḥ kavivaro granthaḥ svayaṃ nirmame //
