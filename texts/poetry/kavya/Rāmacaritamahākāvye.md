# Rāmacaritamahākāvye

### prathamaḥ sargaḥ

atha mālyavataḥ prasthe kākutsthasya viyoginaḥ /  
durnivārāśrusaṃvego jagāma jaladāgamaḥ //

 *(atha mālyavataḥ prasthe kākutsthasya viyoginaḥ /  
durnivārāśrusaṃvego jagāma jaladāgamaḥ //)* 
śaśāma vṛṣṭir meghānām utsaṅge tasya bhūbhṛtaḥ /  
virarāma na rāmasya dhārāsantatir aśruṇaḥ //

 *(śaśāma vṛṣṭir meghānām utsaṅge tasya bhūbhṛtaḥ /  
virarāma na rāmasya dhārāsantatir aśruṇaḥ //)* 
itas tataḥ pariṇatiṃ bheje barhiṇakūjitam /  
hā priye rājaputrīti na rāmaparidevitam //

 *(itas tataḥ pariṇatiṃ bheje barhiṇakūjitam /  
hā priye rājaputri iti na rāmaparidevitam //)* 
kāpy abhikhyā virajasoḥ sūryācandramasor abhūt /  
dāśarathyos tathaivāsīd ayogopahatā ruciḥ //

 *(ka āpy abhikhyā virajasoḥ sūryācandramasor abhūt /  
dāśarathyos tatha aivā asīd ayogopahatā ruciḥ //)* 
nirmalendu nabho reje vikacābjaṃ babhau saraḥ /  
paraṃ paryaśruvadanau mamlaturbhrātarāvubhau //

 *(nirmalendu nabho reje vikacābjaṃ babhau saraḥ /  
paraṃ paryaśruvadanau mamlaturbhrātarāvubhau //)*

āsīt tathaiva tu mano rāmasyotkalikākulam //

 *(smartavyakalikājālaṃ jajñe kuṭajakānanam /  
āsīt tatha aiva tu mano rāmasya utkalikākulam //)*

upakriyāyāḥ sadṛśaṃ nārebhe ravisūnunā //

 *(prapede punar udbhedaḥ śucinā kacchaketakaiḥ /  
upakriyāyāḥ sadṛśaṃ nā arebhe ravisūnunā //)*

 *(ākṛṣṭamālatīgandhaḥ siṣeve rāghavaṃ marut /  
ānītamaithilīvārtas tam ārtaṃ na tu mārutiḥ //)*

āste 'smāsu na sīteti śaṃsantya iva nimnagāḥ //

 *(rāmāya pūrāpagamavyaktoddeśāś cakāśire /  
āste 'smāsu na sīta īti śaṃsantya iva nimnagāḥ //)*

nūnaṃ tenānutāpena jagmur jaladarājayaḥ //

 *(yadārdraviraho rāmaḥ prāpitaḥ prāṇasaṃśayam /  
nūnaṃ tena anutāpena jagmur jaladarājayaḥ //)*

mārgadānāparādhinyo gatā dūraṃ bhayād iva //)*

kacchāḥ kāśacchalād ūhur itīva palitāgamam //

 *(tasyā akṛtiviśeṣasya viśeṣāt kaṣṭam īdṛśam /

paśyantyā iva kaṣṭāṃ tām avasthāṃ maithilīpateḥ /

 *(yayau virahasaṃvartaḥ padminīrājahaṃsayoḥ /

 *(śāntanirjharajhātkāradhārāḥ śikhariṇo babhuḥ /  
rāmasya viśadālāpaśuśrūṣānibhṛtā iva //)*

 *(tasya cakruś camatkāraṃ vyatītasamayā api /

 *(adṛśyanta puras tena khelāḥ khañjanapaṅktayaḥ /

 *(abravīd atha kālajñas tatkālapratipattaye /

utsāhakamalasya ayaṃ vikāsāvasaras tava //)*

madaṃ gopatayo gṛhṇanty abhiyogaṃ jigīṣavaḥ //)*

 *(sudūronnataparyantās tīryante saṃkramair iva /

 *(ito 'vatīryatāṃ prāsthād asvāsthyam idam ujjhyatām /
